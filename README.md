# Práctica 2 - Manejo de Contenedores, Acciones GitHub y Jenkins

Repositorio de práctica para la materia de Técnicas de Integración de Código. En este proyecto se configuran flujos automatizados con GitHub Actions para notificar por correo electrónico cuando se realizan cambios en las ramas `main`, `feature_a` y `feature_b`, además de trabajar con contenedores de Docker y Jenkins.
